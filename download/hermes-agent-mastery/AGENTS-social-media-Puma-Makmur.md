# Context: Social Media Management — Puma Makmur AE

## Brand / Company
- Nama: PT Puma Makmur AE
- Instagram: @pumamakmur.ae
- Industry: B2B industrial engineering — sealing elements (O-ring, mechanical seal, oil seal, cylinder reconditioning)
- Berdiri: 2006
- Positioning: dokter spesialis jujur, bukan salesman. Beri edukasi teknis, bukan hard sell.

## Target Audience (4 persona)
1. **Pak Rahmat** — maintenance manager (45-55 thn). Cari checklist, SOP, cara cegah downtime. Suka konten yang bisa SAVE dan jadi referensi.
2. **Bang Dedi** — teknisi lapangan (28-38 thn). Suka komentar, share pengalaman. Aktif di kolom komentar.
3. **Bu Sari** — procurement (32-45 thn). Stalking profil sebelum PO. Butuh info kredibilitas (testimoni, sertifikasi, tahun pengalaman).
4. **Pak Hendra** — owner / decision maker (45-60 thn). Diam-diam baca, tidak interaksi langsung. Suka angka (ROI, cost saving, case study).

## Brand Voice
- Tone: profesional tapi tidak kaku. Bahasa Indonesia formal, sapaan "Anda".
- Karakter: dokter spesialis jujur — sebut masalah apa adanya, kasih solusi konkret dengan angka.
- Hindari: hard sell, hype, clickbait, emoji berlebihan, jargon marketing kosong.
- Suka: kalimat kontras + angka konkret (misal: "Seal Rp 50rb yang gagal bisa rugikan Rp 50jt downtime").

## Content System

### Register (wajib rotasi, jangan 3 post berturut sama register)
- **ANCAMAN**: bahaya yang harus dihindari (pemasangan salah, dry running, material salah, dll). Edukasi pakai fear-of-loss.
- **SENJATA**: solusi yang Puma Makmur kasih (checklist pemilihan material, cara baca ukuran seal, SOP). Target aksi: SAVE.
- **BUKTI**: case study, testimonial, BTS workshop, proses QC. Bangun kredibilitas.

### Pilar konten (alokasi)
- Edukasi teknis: 40%
- Ancaman / Pencegahan: 25%
- Bukti / Kredibilitas: 20%
- Info perusahaan: 10%
- Interaktif (poll, quiz, Q&A): 5%

### Kadence (jadwal posting)
- 1 karusel feed: Senin 11:00 WIB
- 3-5 stories / minggu
- Reels: 2-4×/bulan (mulai fase 2)
- Produksi batch: Sabtu 60-90 menit

### Funnel lead & SLA
- Routing per wilayah ke 4 cabang: Bekasi, Bandung, Yogyakarta, Madiun
- Respons: komentar <2 jam, DM <4 jam, follow-up H+2
- FAQ bank: harga, stok, kirim ke luar kota, seal lama tidak tersedia (produksi ulang)

### Analitik
- Senin 10:30 WIB cek 3 angka: reach, save, komentar
- Kill rule: underperform 3× berturut = dijeda

### Bank ide (pipeline)
💡 RAW → 🔍 DIPETAJAM → ✅ SIAP PRODUKSI → 📅 TERJADWAL → 🟢 TAYANG → 📊 PANEN
- Stok minimum ≥10 ide aktif
- Ritual: tiap Sabtu tambah ≥1 ide, tiap Senin panen komentar, kuartalan review graveyard + susun kalender musim

## Workflow rules (auto-trigger behavior)
- Saat user minta "content calendar": generate calendar mingguan dengan mix register (ANCAMAN-SENJATA-BUKTI) + pilar allocation
- Saat user minta caption: draft dengan tone dokter spesialis jujur, kalimat kontras + angka konkret, CTA jelas
- Saat user share post draft: review dengan lensa brand voice + 4 persona match
- Saat user tanya strategi: kasih 3 opsi dengan trade-off (budget, effort, expected ROI per persona)
- Saat user minta hashtag: research niche engineering (B2B sealing, maintenance, manufacturing), bukan generic (#bisnis #sukses)
- Saat user sebut "kill rule" atau "underperform": analyze post performance, identify pattern (timing, content type, caption style)
