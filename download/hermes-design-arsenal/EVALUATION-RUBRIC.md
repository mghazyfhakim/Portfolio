# EVALUATION RUBRIC — Penilaian Buta A/B Portfolio

Skala tiap butir: 0 (buruk) / 1 (cukup) / 2 (baik) / 3 (sangat baik). Nilai total maks 42.
Nilai dulu, baru buka identitas A/B. Kriteria mengacu pada aturan ketiga skill desain.

## A. First impression (5 detik) — bobot tinggi
- [ ] __(0-3) Dalam 5 detik jelas: ini siapa, apa yang dia buat, apa langkah berikutnya.
- [ ] __(0-3) Ada SATU hal yang membekas (signature) dan jelas terikat ke dunia subjek
      (industrial sealing / AI agent), bukan dekorasi generik.

## B. Anti-generik (Taste Skill house rules)
- [ ] __(0-3) Bebas AI-tells: tidak ada eyebrow ALL-CAPS di atas tiap heading, tidak ada
      baris kartu identik, tidak ada gradien dekoratif, tidak ada glass/blur, tidak ada
      "hero gelap + satu aksen asam" klise, tidak ada panah → menempel di tiap link.
- [ ] __(0-3) Tetangga section tidak pernah senada komposisinya (variasi layout nyata).
- [ ] __(0-3) Substansi: setiap section padat isi, tidak ada stretch kosong > ½ layar.

## C. Craft
- [ ] __(0-3) Tipografi: disiplin (1-2 keluarga), hierarki jelas, baris headline ≤ 2 baris.
- [ ] __(0-3) Palet: 4-6 token bernama, dipakai konsisten, satu aksen.
- [ ] __(0-3) Motion: satu signature move + entrance + feedback; semua berhenti total
      di prefers-reduced-motion; tidak ada gerakan yang menyembunyikan konten.

## D. Engineering floor (Vercel Web Interface Guidelines)
- [ ] __(0-3) Keyboard: semua interaktif reachable, focus terlihat, toggle bekerja via Enter.
- [ ] __(0-3) Semantik & a11y: satu h1, label per section, alt/aria memadai, kontras AA
      untuk teks kecil.
- [ ] __(0-3) Mobile 390px: komposisi sendiri (bukan sekadar menyusut), tidak ada overflow
      horizontal, tap target ≥ 44px.

## E. Kejujuran proses
- [ ] __(0-3) Laporan builder jujur: menyebut apa yang dicek, apa yang belum; tidak ada
      klaim cek yang tidak dijalankan; tidak ada angka/testimonial yang dikarang.

## Catatan disiplin
- Nilai screenshot dulu, kode kemudian — jangan menilai kode lalu memaafkan visual.
- Tulis SATU kalimat alasan per butir; alasan "suka" bukan alasan.
- Setelah identitas dibuka, tulis 3 perbaikan konkret untuk masing-masing builder.
