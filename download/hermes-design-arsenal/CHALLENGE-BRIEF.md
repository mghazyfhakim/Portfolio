## Method (mandatory)

Use your installed skills in this order:
1. `frontend-design` — pick ONE explicit aesthetic direction grounded in the subject's
   world. State it before writing code. Avoid every "AI tell" it lists.
2. `design-taste-frontend` — set your three dials (DESIGN_VARIANCE, MOTION_INTENSITY,
   VISUAL_DENSITY) and state their values. Build with substance, not ornaments.
3. `design-md` — write your chosen direction as a DESIGN.md in the project root first,
   then build from it.
4. `web-design-guidelines` — audit your own code before finishing; report findings as
   file:line and fix them.
5. `playwright-visual-check` — screenshot your result (desktop + mobile), read console
   and page errors, fix, and re-check before declaring done.
